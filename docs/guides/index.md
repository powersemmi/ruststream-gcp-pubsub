# Guides

`ruststream-gcp-pubsub` is the Google Cloud Pub/Sub broker for
[RustStream](https://powersemmi.github.io/ruststream/latest/), built on
[google-cloud-pubsub](https://docs.rs/google-cloud-pubsub), the official client.
The guides take a Pub/Sub service from installation to production.
Start with [Getting started](getting-started.md).
