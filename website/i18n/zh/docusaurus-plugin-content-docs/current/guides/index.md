# 指南

`ruststream-gcp-pubsub` 是 [RustStream](https://powersemmi.github.io/ruststream/latest/zh/) 的
Google Cloud Pub/Sub Broker，构建在官方客户端 [google-cloud-pubsub](https://docs.rs/google-cloud-pubsub) 之上。
