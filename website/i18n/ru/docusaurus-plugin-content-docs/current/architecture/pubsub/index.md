# Темы

Тема Pub/Sub передаёт каждое сообщение всем подпискам на неё, а подписчики одной подписки делят её
сообщения между собой.

<Diagram name="topics" words={words} />

Издатель называет тему и ничего больше. Подписка - самостоятельный ресурс, привязанный ровно к
одной теме. У темы может быть много подписок.

Подписка получает сообщения, которые опубликованы в её тему после того, как она создана. Каждая
подписка получает собственную копию каждого сообщения, поэтому billing и audit никогда не забирают
сообщения друг у друга.

Подписчики одной подписки делят её сообщения: каждый получает свою часть, и никакие два не получают
одну и ту же. Новый подписчик подписки распределяет её нагрузку. Новая подписка добавляет ещё
одного читателя всех сообщений.

В `ruststream-gcp-pubsub` обработчик называет подписку, которую читает, через
[`GooglePubSub`](api:ruststream_gcp_pubsub::GooglePubSub) или простым именем, а издатель называет
тему, в которую пишет. Эта модель взята у Google
([обзор подписок](https://docs.cloud.google.com/pubsub/docs/subscription-overview),
[основы Pub/Sub](https://docs.cloud.google.com/pubsub/docs/pubsub-basics)). Как подписчик держит
сообщение, пока работает с ним, показывает страница [Аренда](leases.md).
