# Руководства

Крейт `ruststream-gcp-pubsub` реализует брокер Google Cloud Pub/Sub для
[RustStream](https://powersemmi.github.io/ruststream/latest/ru/). Он построен на официальном
клиенте [google-cloud-pubsub](https://docs.rs/google-cloud-pubsub).
